# platform-commons

Biblioteca de plataforma compartilhada: logging JSON estruturado, mascaramento de dados pessoais (LGPD), propagação de traceparent, Problem Details e utilitários Kafka. Artefato `br.com.motorfraude:platform-commons`.

Depende do pom pai. `./mvnw verify` roda os testes; `./mvnw install` instala em `~/.m2`.
Visão geral: https://github.com/luizavramos/fraud-detection-engine
